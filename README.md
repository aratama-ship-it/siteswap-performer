# Siteswap Performer

Browser-only juggling performer for 3-ball vanilla siteswap (Three.js, deterministic by seed).

- Open the site and add `?routine=3x4+531x2+3x4` (space-separated `<siteswap>x<repeats>` tokens).
- `?mode=judge` shows the blind A/B judging view.
- Built output only; the version is shown top-left.
